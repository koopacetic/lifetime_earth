# Pages 452–468 (−2,315,000,000 to −2,230,000,000)
_Dug: 2026-11-23. Status: 17 candidates, 6 added (all in the stretch)._

## Context
Late Siderian to early Rhyacian (Rhyacian starts at −2,300,000,000, page 455), Paleoproterozoic, right after the
Great Oxidation Event. Before the dig the stretch was the second-longest empty run in the book (17 pages): only
spans passed through it. Neighbours: `huronian-glaciation` (p449, span 2.45–2.21 Ga), `tectono-magmatic-lull`
(p450, mid entry of a 2.45–2.20 Ga span; condie2009, neil2025, added by the 436–450 dig the same day),
`great-oxidation` (p451, 2.32 Ga), `yarrabubba-impact` (p469, 2229 Ma), `lomagundi-excursion` (span starts 2.22 Ga, p471).
The 436–450 dig owns Arrowsmith orogeny material (neil2025, partin2023).
Rock of this age: Transvaal Supergroup (Pretoria Group: Timeball Hill, Hekpoort, Rietfontein), Huronian Cobalt Group
(Gowganda, Lorrain, Gordon Lake, Bar River), Turee Creek and lower Wyloo groups (Pilbara), Karelia, the Rae and Slave
cratons, India (Dharwar, Bastar, Singhbhum dyke swarms), North China (Xiong'ershan). The period is famously quiet:
the "tectono-magmatic lull" (Condie 2009: 2.45–2.2 Ga; Spencer 2018: 2.3–2.2 Ga), so few precise ages exist.

## Searched, nothing usable
- **Impacts**: none dated inside; Yarrabubba (2229 Ma) sits on p469; next is Vredefort (p510).
- **Glaciations**: the third Transvaal glaciation (Rietfontein/upper Timeball Hill) and the Gowganda have only
  bracketing ages (2.31 below / ≤2.25 above); no honest point date. Fourth glaciation (Makganyene/Chocolay) ~2.22 Ga or later.
- **Life**: no microfossil or biomarker record firmly dated 2.315–2.23 Ga (Turee Creek ages uncertain, see #15).
- **Earth–Moon**: no tidal rhythmite data in the window (williams2000 point is 2,450 Ma).
- **Ore deposits**: none found with a precise age in the window (Kalahari manganese ~2.4 Ga; Birimian gold later).
- **Crustal growth**: the window *is* the lull; nothing to add beyond #6/#7.
- **Palaeomagnetism**: Malley pole is the only one in the window (used in #1).
