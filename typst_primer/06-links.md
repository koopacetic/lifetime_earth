# 6. Further reading

## Start here
- Tutorial (writing → formatting → advanced styling → templates): https://typst.app/docs/tutorial/
- Syntax cheat sheet (all three modes): https://typst.app/docs/reference/syntax/
- Scripting (let, if, for, functions, methods): https://typst.app/docs/reference/scripting/
- Styling (set and show rules): https://typst.app/docs/reference/styling/
- Context: https://typst.app/docs/reference/context/

## Reference by area
- Foundations (types, content, arrays, dicts, strings): https://typst.app/docs/reference/foundations/
- Model (heading, par, cite, bibliography, figure, outline): https://typst.app/docs/reference/model/
- Text: https://typst.app/docs/reference/text/
- Layout (page, block, box, grid, place, length): https://typst.app/docs/reference/layout/
- Visualize (line, rect, image, color, stroke): https://typst.app/docs/reference/visualize/
- Data loading (json, csv, yaml, read): https://typst.app/docs/reference/data-loading/
- Introspection (counter, state, query, here, metadata): https://typst.app/docs/reference/introspection/
- Math: https://typst.app/docs/reference/math/

## Coming from LaTeX
- Guide for LaTeX users: https://typst.app/docs/guides/guide-for-latex-users/
- Page setup guide: https://typst.app/docs/guides/page-setup-guide/
- Tables guide: https://typst.app/docs/guides/table-guide/

## Tooling
- CLI and source: https://github.com/typst/typst
- Changelog (check before upgrading `typst` in requirements.txt): https://typst.app/docs/changelog/
- Python bindings (used by tools/build.py): https://github.com/messense/typst-py
- Tinymist (VS Code language server + live preview): https://github.com/Myriad-Dreamin/tinymist
- Typst Universe (packages and templates): https://typst.app/universe/
- CeTZ (drawing, if the ruler/diagrams get ambitious): https://typst.app/universe/package/cetz
- Hayagriva (Typst's bibliography engine, BibTeX handling): https://github.com/typst/hayagriva
- CSL styles (for `cfg.bibliography.style`): https://www.zotero.org/styles
