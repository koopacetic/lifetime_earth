## Abstract
v.0.0.1 First full release. Provides a light and easily-accessible solution to working with Sepkoski's compendium. Package includes: Sepkoski's raw fossil marine animal genera compendium (Sepkoski, 2002). Sepkoski's compendium with updated first and last appearance intervals to be consistent with international geological stages. A table linking intervals in Sepkoski's compendium with the International Geological Time Scale 2022. A function for plotting Sepkoski's evolutionary fauna for easy reproduction in presentations, articles, etc.
